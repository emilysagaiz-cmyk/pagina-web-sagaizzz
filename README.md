# 📝 Meu Blog

Projeto de um blog desenvolvido para praticar conceitos de **HTML, CSS, Flexbox e JavaScript**.

O projeto foi criado como atividade de aprendizagem e tem como objetivo desenvolver uma página organizada, responsiva e visualmente agradável.

---

## 🚀 Tecnologias utilizadas

- HTML5
- CSS3
- Flexbox
- JavaScript
- Git/GitHub
